PhaseZero Catalog Service
Overview
A lightweight and modular Product Catalog Microservice built using Spring Boot 4, MySQL,
JPA/Hibernate, and RESTful APIs.
The service enables product creation, retrieval, filtering, and inventory value calculations.
Features
- Add new product
- Get all products
- Search by part name
- Filter by category
- Sort by price
- Calculate total inventory value
- Global exception handling
- Clean layered architecture
Tech Stack
- Java 17
- Spring Boot 4
- MySQL 8+
- Spring Data JPA
- Jakarta Validation
- Maven
- Embedded Tomcat
Architecture
controller/
service/
repository/
entity/
exception/
PhasezeroCatalogServiceApplication.java

API Endpoints
POST /products
GET /products
GET /products/search?name=laptop
GET /products/category?category=electronics
GET /products/sort/price-asc
GET /products/total-value
Sample Add Product Request:
{
"partNumber": "PN-1001",
"partName": "laptop",
"category": "electronics",
"price": 45000,
"stock": 10
}
Entity Details
id - autogenerated
partNumber - unique
partName - lowercase normalized
category - lowercase normalized
price >= 0
stock >= 0
Exception Handling
Centralized handler using GlobalExceptionHandle
